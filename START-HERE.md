# Modular Development Framework

Use a regular ChatGPT Project chat connected to GitHub for Architecture. Use Codex with the local repository checkout for Builder work.

Normal flow: `Initialize Framework` → `Create Milestone` → `Implement Milestone` → `Review` → `Address Review` when needed → user acceptance → `Create Milestone`.

Current repository state comes from `workflow-state.json`. Package identity comes from `framework.json` and the authenticated ZIP digest.

See `architecture-workflow.md`, `builder-workflow.md`, and `commands-reference.md`.
